1. 为词汇排课新增 `unseenWordCount` 与 `unstableWordCount` 失败测试，修正首页进度文案。
2. 为总巩固会话新增版本化、内容白名单、账户隔离和旧数据迁移测试，再实现最小存储适配。
3. 为历史曝光选材添加纯函数和测试，将其接入每日听力/阅读/翻译/写作已有入口，不改变内容格式。
4. 在听力页补充分层训练路线与可访问的状态说明，并增加组件测试。
5. 扩展 Playwright：完成一轮、刷新、开始第二轮、刷新后继续；加入损坏会话恢复场景。
6. 运行定向测试、全量 `pnpm release:verify`、审查差异、提交并推送 `main`，等待 GitHub Pages 成功后核对线上资源。

外部阻塞不伪装完成：Supabase 生产凭据、服务器推送服务、授权真人多口音音频。
