# 听力基础提升与质量补齐设计

## 目标

修复“开始学习”在今日页无可见响应的问题，并为英语基础薄弱学习者增加可自动判定的听力训练闭环。同步解决审计中会直接影响学习、离线更新和打印使用的问题。

## 交互设计

- 漏学提醒的主按钮进入“错题复习”，普通定时提醒进入今日第一项高频词训练；点击后立即关闭提醒。
- 听力页新增“基础听力三步法”：关键词预热、逐句辨词、听写复盘。辨词题从当前材料自动生成，答案由系统判定，不依赖手动标记。
- 基础薄弱阶段默认提示使用 0.75 倍速；完成辨词后引导回到 1 倍速。错误词若能匹配高频词库，则自动加入复习卡。
- 听写采用最长公共子序列对齐，展示正确、漏听和多写词，避免一个漏词拖累后续整句。
- 长对话原文显示 Woman/Man 标签；合成音频在只有一个系统英文声线时，使用不同语速区分角色。

## 内容与可靠性

- 打印题册为阅读完形/匹配题加入完整语境，为听力题加入音频入口；同组材料只打印一次。
- PWA 音频缓存改为网络优先并升级缓存版本，离线时仍回退缓存，避免网页更新后继续播放旧音频。
- 写作范文去除重复主体，内容审计新增重复检测。
- 保存提示只陈述真实能力：默认保存到本机；仅在确实配置云端时说明跨设备同步。
- 增加题库依据说明：训练为原创仿真，不冒充历年真题，并说明能力标签与官方题型结构的关系。
- 增加基础安全元信息。GitHub Pages 无法自定义全部响应头，因此只加入可在静态页面生效的 CSP 与 referrer policy。

## 限制

- 当前 GitHub Pages 没有后台推送服务，提醒仍需打开应用后触发；界面继续明确说明，不伪装成后台通知。
- 当前部署未提供 Supabase 公共配置，学习记录默认只在当前浏览器；保留导入导出备份路径，不声称已经云同步。
- 系统未安装 ffmpeg，本轮不转换 WAV，避免引入手机浏览器兼容性风险。

## 验收

- 提醒按钮在今日页点击后进入明确的新训练页面。
- 基础听力辨词可自动判分，错误高频词可进入复习。
- 听写漏一个词后，后续正确词仍能被识别。
- 打印材料具有可作答所需语境或音频入口。
- 更新后的音频不被旧 CacheFirst 缓存长期覆盖。
- 单元、端到端、类型、静态检查、构建和发布检查全部通过。
