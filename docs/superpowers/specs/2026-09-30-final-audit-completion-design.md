# 最终审查缺口完善设计

## 目标

在不清空现有学习记录、不改变四级备考目标的前提下，补齐最终审查发现的学习闭环、可信度、兼容性、内容校验、跨设备部署与浏览器回归测试缺口。

## 设计

### 无提示词汇总巩固

开始巩固时创建一次固定随机队列；同一轮内每个单词只出现一次。每题保存答案与掌握状态，答错继续写入错题复习。页面显示本轮进度，结束后显示测试数、答对数、遗忘数，并允许开始新一轮。队列仅存在页面会话中，不改变已有 IndexedDB 数据结构。

### 间隔复习约束

错题复习列表继续显示未来复习项目，但未到 `nextReviewAt` 的项目不可启动正式检测，并明确显示“未到复习时间”。这样不会让提前练习被误解为完成一次间隔复习。

### 评分可信度

诊断结果与今日页统一显示“训练参考估分”、样本题数和“初步可信度”，继续保留非官方成绩声明。规则化作文和翻译反馈不宣称人工阅卷能力。

### 浏览器兼容

所有生产流程通过统一 `createId()` 生成记录 ID：优先使用 `crypto.randomUUID()`，旧浏览器缺失该接口时使用时间、随机数和计数器组合的本地唯一 ID。

### 内容完整性

扩展 v1 内容审计，对 800 词、126 搭配、15 语法、听力、阅读、翻译、作文和模考逐项检查必填字段、合法选项、答案范围、引用关系和音频路径。保留已有多样性、数量和例句质量审计。

### 云同步部署

不提交或伪造 Supabase 密钥。新增严格云模式验证命令和 GitHub Actions 可选的 `REQUIRE_CLOUD_SYNC` 仓库变量：开启后，缺少两项 Supabase Actions Secret 会让部署失败；未开启时保留离线可用并在部署摘要、账户页和文档中明确提示。配置完成后，现有同步引擎自动启用。

### 回归测试

增加组件和浏览器测试，覆盖无重复完整轮次、轮次总结、未来复习锁定、旧浏览器 ID 回退、估分可信度提示、v1 全量内容错误检测，以及主要页面核心按钮可操作性。

## 成功标准

- 同一轮词汇总巩固不重复，结束后有可核对报告。
- 未到期复习不会被误计为正式检测。
- 旧浏览器缺少 `randomUUID` 时仍能保存作答。
- 全量 v1 内容进入发布校验。
- 云同步可由仓库变量强制要求，缺密钥时不会悄悄发布成本地模式。
- 完整发布验证通过，现有学习数据结构不迁移、不清空。
