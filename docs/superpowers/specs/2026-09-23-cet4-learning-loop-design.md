# 四级向前：完整学习闭环设计

## 背景与目标

“四级向前”服务于一名英语基础薄弱、计划参加 2026 年 12 月 12 日 CET-4 笔试、每天可投入 60 分钟的学习者。现有应用已经具备响应式界面、PWA、知识库、听力播放、基础练习、打印和本地存储骨架，但题库、作答、判分、错题、复习、进度、模考和跨设备同步尚未形成可靠闭环。

本次改造保留现有视觉风格、公开访问链接和离线优先架构，通过增量补全把应用提升为可长期使用的四级备考工具。成功标准是：学习者能在手机或电脑上完成真实的每日计划，断网时不丢答案，登录后跨设备同步，并能完成符合 CET-4 结构的限时模拟与 A4 纸质练习。

## 范围

### 本次包含

- 真实的每日 60 分钟学习计划、完成状态、连续学习天数和薄弱项。
- 听力、词汇、语法、阅读、写作和翻译的完整练习入口。
- 将现有 800 词、126 个搭配、15 个语法主题、24 套听力、30 套阅读、12 套翻译、12 个写作题和 6 套模拟卷接入实际学习流程。
- 客观题判分、答案解析、错题归档、错误原因和间隔复习。
- 写作与翻译草稿自动保存、自查清单和参考答案。
- 125 分钟完整模拟考试、自动保存、恢复、交卷及分项分析。
- IndexedDB 离线保存、Supabase 登录同步、同步状态和数据备份。
- 可配置的 A4 练习册、独立答案解析页、答题空间和自动页码。
- 手机端完整导航和 360px 最小宽度适配。

### 本次不包含

- AI 作文评分、真人批改或口语考试训练。
- 社区、排行榜、付费订阅或社交功能。
- 冒充或复制受版权保护的官方历年真题。
- 根据原始分数推算官方 710 分制成绩；应用只展示练习正确率、完成度和能力趋势。

所有练习在界面中标注为“依据四级题型与高频考点编写的原创仿真练习”。

## 方案选择

采用增量补全方案：保留 React、React Router、Dexie、Supabase、现有组件和内容文件，通过统一领域模型与仓储接口接通各页面。

不采用整体重写，因为现有 PWA、音频与部署已经可用，重写会增加回归风险；也不采用只修按钮的最小补丁，因为那无法形成可信的学习数据和复习闭环。

## 总体架构

应用继续采用离线优先的数据流：

1. 页面通过领域服务读取题库并提交学习事件。
2. 学习事件首先写入本机 Dexie，界面立即更新，不依赖网络。
3. 登录用户的待同步操作进入队列，由同步引擎在联网时上传 Supabase。
4. 另一设备登录后拉取远端记录并合并至本机。
5. 统计服务仅根据真实学习事件计算计划、连续天数、正确率和薄弱项。

内容文件保持只读并带版本号；用户数据只保存内容 ID 和内容版本，后续更新题库时不会复制整份题目到每条记录。

## 领域数据

### Attempt

每次提交保存：`id`、`userId`、`deviceId`、`questionId`、`contentVersion`、题型、答案、正误、练习分数、用时、模式、错误原因、创建时间。答题记录采用追加写入，不因跨设备同步互相覆盖。

### ReviewCard

每个需要复习的知识点或题目保存：来源题目、到期时间、复习阶段、连续正确次数、最近结果和更新时间。首次答错当天进入复习，推荐间隔为 0、1、3、7、14 天；再次答错重置到第一阶段，答对后进入下一阶段。

### StudyTaskCompletion

记录日期、计划任务 ID、任务类型、目标分钟、完成时间和来源练习。首页根据当日记录展示“开始、继续、已完成”。

### Draft

写作和翻译草稿保存题目、正文、设备和更新时间。跨设备冲突采用较新的 `updatedAt`，本机在远端确认前保留原副本。

### ExamSession

保存试卷 ID、开始时间、剩余时间、当前分区、已作答案、状态和最后自动保存时间。每 30 秒及每次切题时保存；关闭浏览器后允许恢复。交卷后的会话不可继续修改。

### UserSettings

保存考试日期、每日学习时长、薄弱项偏好、播放速度和内容显示偏好。考试日期默认 2026-12-12，但允许用户修改。

## 页面与功能

### 今日学习

- 根据距离考试的阶段、到期错题、未完成任务和近 14 天正确率生成总计 60 分钟的计划。
- 每个任务可进入对应练习，并显示未开始、进行中或已完成。
- 连续学习天数以当天是否完成至少一个有效任务计算。
- 薄弱项基于至少 5 次有效作答后计算；样本不足时显示“正在积累数据”，不展示伪造百分比。

### 听力精练

- 保留播放、暂停、分句、循环、速度和文本模式。
- 每套题支持全部问题，不只展示第一题。
- 未选择答案时禁止提交并给出提示。
- 提交后显示正误、正确答案、中文解析和定位句，并保存答题记录。
- 错题生成 ReviewCard；重新练习时可直接回到相同音频与题目。

### 专项练习

- 首页提供词汇、语法、阅读、写作、翻译分类和题量选择。
- 客观题在练习模式逐题反馈；考试模式直到交卷才反馈。
- 阅读覆盖选词填空、长篇匹配和仔细阅读。
- 写作与翻译接入现有 SubjectiveEditor，支持字数统计、自动草稿、自查和参考答案。
- 每组结束显示完成数、正确率、用时、错题和下一步建议。

### 错题与复习

- 默认展示今日到期项目，可按题型、错误原因和掌握状态筛选。
- “重新练习”打开真实题目；结果更新 ReviewCard，而非创建静态示例。
- 支持将题目标记为“稍后复习”或“已掌握”。

### 完整模考

- 按官方结构组织：写作 30 分钟、听力 25 分钟、阅读 40 分钟、翻译 30 分钟，总计 125 分钟、57 题。
- 模考中不显示答案和解析；分区结束后按考试顺序锁定相应作答。
- 支持自动保存、刷新恢复、主动交卷和时间到自动交卷。
- 结果展示完成度、客观题正确率、各部分耗时、薄弱知识点和主观题自查，不伪造官方 710 分制分数。

### 高频知识

- 词汇、搭配和语法支持搜索、收藏、待复习和已掌握。
- 掌握状态进入本地数据库并参与每日计划。

### 账户、同步与备份

- 手机与电脑都显示账户入口。
- 未登录时明确显示“仅保存在本机”；登录后显示最近同步时间、待同步数量和失败状态。
- Supabase 使用邮箱密码认证和行级安全策略，用户只能访问自己的数据。
- 断网或同步失败不阻塞学习；界面显示“已保存在本机，联网后重试”。
- 提供 JSON 导出、导入和清空本机数据。导入先校验版本和结构，错误文件不得覆盖现有数据。

### A4 打印

- 用户可选择每日练习、专项练习或完整模拟卷。
- 题目页和答案页分离，主观题与客观题均预留适当答题空间。
- 答案页包含正确答案、中文解析和知识点，不再只提示返回应用查看。
- 页码根据实际生成页数计算；浏览器打印和保存 PDF 使用相同版式。

## 同步与冲突处理

- Attempt 使用全局唯一 ID，按 ID 去重后合并，绝不覆盖另一设备的历史作答。
- ReviewCard、StudyTaskCompletion 和 UserSettings 按实体 ID 合并，较新 `updatedAt` 生效。
- Draft 以较新版本为主；检测到双方在上次同步后均修改时保留冲突副本供用户选择。
- 删除操作写入带时间戳的墓碑记录，防止被另一设备旧数据恢复。
- 同步队列采用指数退避；用户主动点击可立即重试。

Supabase 未配置或暂时不可用时，应用自动保持离线模式，并继续提供导出与导入。

## 错误处理

- 音频错误保留当前答案，并提供重试和文本模式。
- 数据库写入失败时不显示“已保存”；保留页面输入并提供重试。
- 题库内容缺失时隔离受影响题目并记录错误，不让整页崩溃。
- 模考恢复时校验题库版本；版本不一致则保存旧会话只读结果并提示开始新模考。
- 路由、懒加载和同步错误均提供明确的返回路径。

## 测试与验收

### 自动测试

- 领域单元测试：计划生成、真实进度、判分、复习间隔、统计、模考计时、同步合并和打印分页。
- 组件测试：听力提交、练习反馈、主观题草稿、错题重练、登录状态和离线提示。
- 端到端测试：首次打开、完成每日任务、错题复习、模考恢复、打印、离线作答、两设备同步。
- 内容审计：所有内容 ID 唯一、引用存在、选项与答案有效、音频路径可访问、模拟卷满足结构。

### 验收标准

- 360px 手机宽度下无横向溢出，所有核心操作可完成。
- 断网刷新后仍能继续学习，之前的答案和草稿存在。
- 听力提交后正误、解析、错题和进度同步更新。
- 专项练习实际使用完整内容库，不再只读取 starter 题组。
- 模考按 125 分钟和官方分区运行，考试中不泄露答案。
- 同一账户在手机和电脑上可看到合并后的学习记录。
- A4 题目、答题区、答案、解析和页码正确。
- 单元测试、组件测试、端到端测试和生产构建全部通过。

## 实施阶段

1. 统一内容适配层与学习数据模型。
2. 完成听力、专项练习、错题和真实进度闭环。
3. 接入写作、翻译、知识掌握状态和完整内容库。
4. 完成 125 分钟模拟考试与结果分析。
5. 完成 Supabase 双向同步、账户状态和数据备份。
6. 完成 A4 生成、全面测试、无障碍与移动端校验。
7. 部署 GitHub Pages 并检查线上音频、路由、PWA 和同步配置。

## 发布与兼容

数据库升级必须使用 Dexie 版本迁移，保留现有答题和草稿。新功能分阶段接入，但每次部署都必须保持旧数据可读。PWA 发布时提示用户刷新到新版本，避免旧缓存与新题库混用。
