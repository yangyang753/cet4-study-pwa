# CET-4 掌握与复习闭环完善设计

## 目标

把高频词、重点搭配、语法、写作和翻译统一纳入可验证的学习闭环。任何内容都不能靠手动按钮变成“已掌握”；只有通过测试和间隔复习才会自动掌握，后续答错会自动降级。手机与电脑继续支持离线使用，启用云端后不得把一名用户的本地数据错误归给另一名用户。

## 掌握规则

1. 高频词和重点搭配使用同一套状态：待学习、学习中、待复习、稳定掌握。
2. 第一次学习只建立学习记录，不直接掌握。词义或搭配测试答对后进入待复习；至少完成多阶段复习后才显示稳定掌握。
3. 任意后续测试答错，立即清零连续阶段，状态改为待复习，并创建立即到期的复习卡。
4. 高频知识页分别显示三个状态分区，已掌握和未掌握不混排；重点搭配不再提供手动“标记为已掌握”。
5. 今日词汇训练同时安排高频词与重点搭配，先复习旧内容，再学新内容。

## 复习系统

1. 仓库同时提供全部复习卡和今日到期卡；“已掌握”读取全部卡片，不因下一次复习时间在未来而消失。
2. 复习分类包含词汇、重点搭配、语法、听力、阅读、写作和翻译。
3. 写作与翻译错题可在复习页重新提交，并获得规则化反馈；语法题保持语法身份，不归入词汇。
4. ReviewCard 与 KnowledgeState 使用同一个阶段规则，避免同一内容在两个页面显示不同掌握状态。

## 数据安全

1. 备份完整保留报名、缴费、准考证和用品状态，并增加回归测试。
2. 导入备份只恢复学习实体，不直接重放来源设备的同步队列；导入后由当前设备按当前账号重新生成需要同步的操作。
3. 未登录时产生的同步操作保持本地待认领；登录时只有在用户明确触发同步的当前本地档案中认领，已经归属其他账号的操作永不上传。
4. 生产环境缺少 Supabase 配置时继续明确显示“仅本机保存”，不伪装成跨设备同步。

## 评估与计划

1. 翻译评价增加分句覆盖、同义义项和最低信息覆盖率；结果仍明确是规则化反馈。
2. 写作与翻译反馈增加基础句法、重复、关键词覆盖和结构检查，不宣称等同官方阅卷。
3. 词汇进度同时预测首次接触和稳定掌握，计算仍需完成的复习阶段；当考试前无法按每日容量完成时提示增加时间。
4. 模考继续以最近三次安全线作为趋势参考，并明确不能保证真实 CET 分数。

## 验收标准

- 重点搭配无手动掌握按钮，并具有测试、自动掌握、答错降级和独立状态分区。
- 今日词汇训练包含重点搭配且复习优先。
- “已掌握”筛选刷新后仍能看到未来复习卡。
- 语法、写作、翻译错题均可从正确分类重新练习。
- 单词第一次答对不再直接显示稳定掌握。
- 备份往返保留 paymentConfirmed，且不导入旧 syncQueue。
- 完整单测、类型检查、lint、构建、内容审计、手机端和离线浏览器测试通过。
