# 中国文化每日翻译与学习可靠性设计

## 目标

基础薄弱的学习者每天先掌握与复习高频词，再用当天词汇完成一段原创“中国文化概况”汉译英。系统自动识别漏用或拼错的目标词，将其降级并加入错题复习。与此同时，修复完整模考静默丢答案、听力可随意重播、阅读翻译强制切段、诊断结果长期不复测与损坏会话恢复不严的问题。

应用继续以 2026 年 12 月 12 日 CET-4 为默认目标，日计划默认严格保持 60 分钟。生产站点仍为本地优先 PWA；跨设备自动同步只有在 GitHub Pages 构建配置有效 Supabase URL 与 Publishable Key 后才能安全启用。

## 题材依据与版权边界

全国大学英语四、六级考试大纲说明翻译内容涉及中国文化、历史及社会发展。公开历年题材分析显示高频主题包括传统艺术与技艺、茶与饮食、节日节气、历史水利与建筑、家庭观念、地理名胜和现代社会发展。

应用不复制历年真题原文或参考译文。新增题目全部为原创仿真段落，采用相同的题材分布、约 140～160 个汉字的目标长度和四级基础句式难度。

## 每日中国文化翻译

新增版本化 `CultureTranslationPrompt` 题库，首批覆盖书法、剪纸、茶文化、二十四节气、传统园林、京剧、丝绸之路、端午习俗、瓷器、古代水利等主题。每题包含中文段落、参考译文、3～5 个目标高频词 ID、关键信息点和记忆表达。

按学习日期稳定轮换题目。词汇调度器接收当天题目的目标词：

- 未接触目标词优先进入今日新词，但不突破动态新词额度；
- 已接触目标词若未到期，作为“翻译强化词”加入当天复习，避免与普通到期旧词混淆；
- 到期旧词仍优先于新词；
- 同一个词在三个列表中只出现一次。

每日词汇流程调整为：到期旧词与翻译强化词补全检测 → 新词学习 → 中国文化汉译英 → 三个重点搭配 → 词义专项题。没有新词时仍使用翻译强化词完成文化翻译。

翻译检测至少要求英文单词数量、结尾标点、基本谓语和目标词形覆盖。目标词允许常见屈折变化。未覆盖目标词自动写入 `KnowledgeState(status='review')` 和拼写 `ReviewCard`；覆盖词只记录练习证据，不直接宣称稳定掌握。保存失败保留全文并提供同一结果重试。完成记录使用稳定日期任务 ID，避免重复提交。

## 今日计划与进度

首页词汇任务明确显示“今日新词、到期旧词、翻译强化词、中国文化翻译主题”。翻译仍包含在词汇块内，因此计划总分钟数不膨胀。今日重点说明该流程会先学词再翻译，不允许跳过词汇直接做题。

## 完整模考可靠性

模考持久化改为显式状态机：`saving / saved / error`。输入使用短防抖保存，切题、切段、交卷和页面隐藏时立即刷新；保存失败时保留内存答案、显示重试，禁止切题、切段和交卷，不能继续声称已保存。

听力部分每个题组只使用一个连续播放器；进入题组后保留播放位置，模考模式隐藏下载并阻止拖动回放，加载失败显示错误和重试。浏览器阻止自动播放时提供一次明确的“开始播放”操作。

阅读与翻译合并为一个 70 分钟答题阶段，共享截止时间并允许自由切换；结果仍分别计分。写作与听力继续按 30/25 分钟锁定。

## 诊断与主观评分

恢复诊断时逐项验证答案 ID、能力类型、分数范围、布尔值、稳定 attempt ID、题目归属和索引一致性；损坏会话废弃并重新生成。

首页显示诊断日期。完成诊断 21 天后或累积 30 次有效练习后显示“建议重新诊断”，但不删除旧档案。规则化写作/翻译评分增加重复填充、明显拼写噪声、目标信息覆盖和句法最低线；仍明确标注不是官方或人工评分。

## 云同步和提醒边界

同步引擎、数据库迁移、认证和 GitHub Actions 环境变量接口已经存在。本次补充部署自检：线上构建若未配置 Supabase，账户页继续明确显示本地模式，并提供导入导出；不得把任何密钥写入仓库。真正的手机电脑自动同步需要站点所有者提供外部 Supabase 项目凭据。

浏览器完全关闭后的可靠推送需要推送服务，本次不伪造支持。保留应用内提醒与通知权限说明，并增加“只有应用运行时检查”的清晰文案。

## 验收标准

- 每天稳定选出一个原创中国文化汉译英题，目标词进入当天词汇学习或强化复习。
- 漏用目标词自动进入错题复习，保存失败不丢全文，重复提交不重复写入。
- 今日计划总分钟数保持设置值，默认 60 分钟。
- 模考保存失败可见且阻止危险导航；听力不能任意回放；阅读和翻译共享 70 分钟。
- 损坏诊断会话不会产生结果，过期诊断会提醒复测。
- 旧记录、备份、离线 PWA、A4 打印和旧诊断继续兼容。
- 单元测试、浏览器测试、类型检查、代码规范、生产构建和 GitHub Pages 验证全部通过。
