# 宽容词义判定与内容质量升级设计

## 目标

让基础薄弱学习者在错题复习和词汇巩固中，只要能写出目标词约三个常见中文义或等价近义表达，就可视为“认识这个词”；英文拼写题和挖空题仍必须拼写准确。同时修复当前词库中的错位、技术词典污染和误导例句，并补齐听力离线下载与线上检查超时保护。

## 判分规则

- 拼写、整词默写和英文挖空继续精确匹配，忽略大小写和首尾空格，不接受错拼。
- 中文词义题把词义拆成概念组，并通过小型受控近义词表匹配等价表达，例如“好处/益处/优势”“得到/获得/取得”。
- 一个词的通过门槛为 `min(3, 可用核心义数量)`；只有一至两个核心义的词仍需命中全部核心义。
- 用户多写合理近义表达不判错；出现明确反义或无关词时不直接用“多写”否定已经达到门槛的答案，但在反馈中不计入命中。
- 反馈显示“已识别 X/Y 个核心义”和仍可复习的常见义，不再要求逐字复刻参考释义。
- 同一判分器供今日严格检测、知识库总巩固和错题复习共用，避免三个入口标准不一致。

## 词库质量

- 修复已定位的三条串行错位记录：`project/prominent`、`contact/contain`、`page/pain`。
- 清除 DOS/计算机命令、文件分配表、机械标签等与 CET-4 常见义无关的字典噪声。
- 清除粘连的词性标签和重复释义，限制展示为适合四级学习的常见义，而不是无差别堆叠整本词典。
- 对损坏词条提供人工校正；自动审计拒绝跨词音标、技术说明、残留词性标签和已知错误释义。
- 例句必须语法完整、包含目标词并与展示的首个常见义一致。对无法由通用模板保证自然度的异常词条使用人工例句。

## 听力与离线

- 每套听力提供“下载本套离线”按钮，写入现有 Workbox 音频缓存；显示下载中、完成、失败和不支持状态。
- 不自动下载全部约 98 MB 音频，避免手机流量和存储被静默占满。
- 保留现有语速控制和逐句精听；明确当前素材为原创合成语音。真实多说话人和不同口音需要合法音源或额外 TTS 服务，不伪装为已经实现。

## 同步、提醒与部署边界

- 继续显示本机模式和 JSON 备份入口。没有 Supabase URL 与发布公钥时不伪装成跨设备同步已启用。
- 继续明确提醒仅在应用打开时检查。真正关闭浏览器后的推送依赖服务器、推送订阅和凭据，不在无外部配置时伪实现。
- 线上资源检查的每个请求增加超时，音频只读取少量字节验证可访问性，避免下载完整大文件或无限等待。

## 验证

- 单元测试覆盖近义表达、三个核心义门槛、少义词、错拼、无关输入和三个入口共用判分。
- 内容审计覆盖三条错位词、技术噪声、词性粘连与例句语义校正。
- 离线下载测试覆盖成功、重复下载、不支持和网络/配额失败。
- 部署检查测试覆盖请求超时和 Range 音频探测。
- 最终运行内容审计、音频审计、466+ 单元测试、Playwright 手机/离线流程、类型检查、Lint、构建与 Pages 验证。

## 执行决定

用户明确要求“不用确认，直接开始”，并已指定由当前会话直接实现和推送；因此本设计在写入并自检后直接进入 Native 执行，不再暂停索取阶段性确认。
