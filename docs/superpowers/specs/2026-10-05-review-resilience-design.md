# 复习界面与本机数据韧性设计

## 目标

将每日旧词复习从单一大卡片升级为清晰、可在手机上操作的主动回忆界面，并补齐本机学习状态在备份、恢复、清空和提醒中的一致性。

## 复习界面

- 页面顶部显示“旧词唤醒”阶段、已完成数量、剩余数量和进度条。
- 主区域保留无提示作答，不显示目标英文答案；按题型仅提供一个需要填写的空白。
- 桌面端使用主答题卡与复习策略侧栏，手机端纵向排列。
- “想不起来”作为明确的次要操作，说明会降级并加入错题复习；提交按钮保持主要视觉层级。
- 题型、挖空位置和原有判分逻辑不变，避免界面调整改变学习证据。

## 本机数据生命周期

- JSON 备份新增可选的浏览器临时学习状态，包括写作/翻译草稿、听写、未完成诊断和总巩固会话。
- 旧版 schemaVersion 1 备份仍可导入；新字段缺失时按空对象处理。
- 只备份白名单内的学习键，不导出设备 ID、账户所有者或备份时间。
- “清空本机数据”同时清空 IndexedDB 与白名单 localStorage 键，保留设备和账户身份。
- localStorage 不可用时，数据库备份、导入和清空仍可完成。

## 草稿恢复

- SubjectiveEditor 先读取本地即时草稿，再异步读取仓库中的已同步/已导入草稿。
- 仅当本地文本为空时采用仓库草稿，避免覆盖用户刚输入的内容。
- 完成恢复后才启动自动保存，防止空内容覆盖导入草稿。

## 学习提醒

- 当日计划全部任务完成后才停止提醒。
- 只完成部分任务时显示剩余任务数并继续引导学习。
- 没有可读取计划时不把任意一次完成记录误判为“今日全部完成”。

## 外部能力边界

- 不声称已经启用跨设备同步或后台推送；生产环境没有 Supabase 密钥与推送服务时继续显示准确提示。
- 不把合成语音伪装成真人或官方真题录音；真人授权音频属于外部素材依赖。
- 写作与翻译反馈继续标注为规则化自查，不声称等同人工阅卷。

## 验证

- 每项行为先添加失败测试，再实施最小修复。
- 覆盖手机宽度、200% 字体、键盘焦点和复习流程。
- 完成后运行完整 release:verify，并验证 GitHub Pages 线上资源。
