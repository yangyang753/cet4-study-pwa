# CET-4 学习闭环完善设计

## 目标

修复审计发现的学习计划负数、翻译错词未进入复习、复习积压不可见、报名提醒过晚、听力计时失真等问题，并补足可信估分、内容质量提示和离线备份状态。所有功能继续支持手机与电脑浏览器、离线本地保存和现有 GitHub Pages 部署。

## 设计

1. 日计划采用可降级预算分配：单词、听力、复习优先，剩余不足时省略专项任务，任意允许时长都不产生负数且总和严格等于设置值。
2. 单词负载先清到期复习，再分配新词；显示全部到期数、当日处理数和积压数。积压达到当日容量时暂停新词，避免“学新忘旧”。完成日期明确为“首轮接触完成”，不冒充稳定掌握。
3. 作答前翻译复用统一单词掌握状态机。漏译词保留原有字段、降级为待复习，并同时创建拼写挖空复习卡；失败时不解锁答案。
4. 报名准备增加校内截止日期和缴费确认。未报名时立即提醒，已报名未缴费时提示尽快完成；准考证和用品仍按考前阶段提醒。
5. 听力每题独立计时，并为一次提交保留稳定 attempt id，保存重试不重复记答题记录。
6. 模考结果增加最近三次安全区判断：不足三次只显示样本不足；三次均达到安全线才显示稳定达标，同时始终声明不是官方标准分。
7. 高频词例句改为按词性、主题和词条散列选择的多模板语境，内容审计检测模板过度重复；生成例句继续明确标注为原创学习语境。
8. 离线模式显示最近备份时间与过期提醒；云同步没有生产密钥时明确说明只能本机保存，不虚构已启用。应用重新打开时显示遗漏学习提示，浏览器关闭后的通知限制保持透明。
9. 工具链忽略本地 worktree 与执行账本目录，保证本机完整 lint 可复现。

## 验收

- 20、30、60、180 分钟计划均无负数，任务分钟总和准确。
- 翻译漏词同时产生 review KnowledgeState 与 word-cloze ReviewCard。
- 到期复习超过容量时显示积压且新词配额为 0。
- 报名、缴费、截止日期提醒有单元测试。
- 听力第二题计时从切题时重新开始，保存重试复用同一 id。
- 估分需至少三次记录才判断稳定性。
- 全量单测、类型检查、lint、构建、内容审计与浏览器端测试通过。
